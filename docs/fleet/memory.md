# Conversation memory

## Automatic log and Dream digest

- AMUX records received human input and the panel replies actually posted to
  Discord, including short tool mirrors. Preserve the original conversation;
  a digest or a cleaner search view never authorizes deleting log records.
- Dream reads that log and writes the day digest. Workers do not keep a manual
  day diary or append decisions, corrections and blockers to daily files.
- Record task state, blockers and delivery evidence in the task's existing
  ledger or receipt. These product records are not a second conversation log.
- Memory and PRIORITIES are short indexes in our own words, with source time
  and a retrievable pointer. Search the original when exact scope matters;
  never manually copy his words. [Authority](authority.md) owns that policy.
- Reusable facts belong at their existing reference/person owner, linked from
  the compact index. Mark uncertainty; do not invent a decision from a summary.
- A scheduled Dream run is not proof of a saved digest. Use the current
  implementation's receipt before claiming that recording or distillation ran.
